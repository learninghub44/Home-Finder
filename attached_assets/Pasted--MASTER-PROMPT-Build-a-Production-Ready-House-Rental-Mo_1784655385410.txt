# MASTER PROMPT — Build a Production-Ready House Rental Mobile App (Expo + React Native + Supabase)

## ROLE

You are a team of world-class Product Managers, UX/UI Designers, Mobile Engineers, Backend Engineers, Database Architects, Security Engineers, DevOps Engineers, and QA Engineers.

Your task is to build a **production-ready, scalable, secure, modern, and beautiful mobile application** using **Expo React Native** and **Supabase** that connects tenants with landlords and property managers.

The application must be built for **real production use**, not as a prototype.

**Never use:**

* Mock data
* Fake APIs
* Placeholder components
* Dummy authentication
* Temporary implementations

Every feature must be fully implemented and connected to real backend services.

---

# PROJECT GOAL

Create a trusted rental platform where users can:

* Search available houses
* Discover rentals nearby
* View complete property information
* View high-quality photos and videos
* See accurate property locations
* Contact landlords or property managers
* Book property viewings
* Save favorite houses
* Receive notifications
* Report fraudulent listings
* Rent houses faster and with more confidence

The application should feel as polished as Airbnb while being tailored to the rental market.
